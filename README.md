# 🎨 TIA Frontend

> Beautiful, responsive frontend for the Thyroid Intelligent Assistant (TIA)

The TIA Frontend provides an intuitive user experience for patients to upload thyroid reports, visualize health insights, track historical trends, and interact with the AI-powered backend.

---

## ✨ Features

- 📄 Upload thyroid reports
- 📊 Interactive dashboard
- 📈 Trend visualizations
- 💬 AI health insights
- 📱 Responsive UI
- 🌙 Modern interface
- ⚡ Fast performance

---

## 🖥 Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- shadcn/ui
- React Router
- Axios

---

## 🚀 Getting Started

Clone the repository

```bash
git clone https://github.com/aamina-codes/tia-frontend.git
cd tia-frontend
```

Install dependencies

```bash
npm install
```

Create a `.env`

```env
VITE_API_URL=http://127.0.0.1:8000
```

Run locally

```bash
npm run dev
```
